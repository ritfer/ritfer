## Проекты и практический опыт

### 1. Интеллектуальная диалоговая RAG-система

* **Демо / Платформа:** [chat.org.by](https://chat.org.by)
* **Архитектура & Стек:** Python, Vector Embeddings, BM25, RRF, Re-ranker, Fine-Tuned Embedding Model, Knowledge Graph, LLM API.
* **Описание:**
* Реализовал отказоустойчивый конвейер гибридного поиска (**Hybrid Search**), объединяющий семантический векторный поиск (Dense Vectors) и лексический поиск (**BM25**).
* Внедрил алгоритм взаимного ранжирования (**Reciprocal Rank Fusion / RRF**) для нормализации и объединения скоров выдачи.
* Настроил этап вторичного переранжирования (**Cross-Encoder Re-ranking**) для максимизации релевантности контекста перед подачей в LLM.
* Выполнил дообучение (**Fine-Tuning**) моделей эмбеддингов под специфику предметной области для повышения точности извлечения чанков.
* Интегрировал элементы графов знаний (**Knowledge Graphs / GraphRAG**) для учета структурных связей и зависимостей между сущностями в документах.
